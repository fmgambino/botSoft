# V42 - Mobile, iconos, favicon y Telegram

Cambios incluidos:

- Header mobile: logo más grande, centrado y alineado con acciones.
- Toggle de tema con ancho corregido.
- Navegación inferior mobile con iconos principales y menú hamburguesa con botón cerrar.
- Iconos SVG minimalistas en todos los módulos.
- Gestión de préstamos usa icono propio, distinto de Inventario.
- Configuraciones permite cargar favicon / icono de instalación de la app.
- Corrección de `openTeamDetail is not defined`.
- Notificaciones del header con popup sin recortes.
- Telegram evita errores visibles cuando el token no tiene formato válido.

Importante Telegram: el Bot Token debe tener el formato completo de Telegram, por ejemplo `123456789:AA...`. Si se configura solo el sufijo, Telegram responde 404.
